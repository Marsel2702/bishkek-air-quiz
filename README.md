# AERA Bishkek — Очистители воздуха

Официальное веб-приложение магазина очистителей воздуха **AERA** в Бишкеке.
Дизайн-система: **Aether Pure** (Plus Jakarta Sans, палитра `#0F172A`, `#0D9488`, `#F8FAFC`, glassmorphism).

- **Production URL:** [https://bishkek-air-quiz.vercel.app](https://bishkek-air-quiz.vercel.app)
- **Целевой рынок:** Бишкек, Кыргызстан (расчеты в сомах KGS, валидация номеров +996, интеграция с WhatsApp и Telegram).

---

## 🚀 Возможности

1. **Индикатор смога в реальном времени:** виджет с переключением районов Бишкека (Центр, Южные микрорайоны, Ак-Орго, Восток-5, Кызыл-Аскер).
2. **Умный конфигуратор:** подбор модели за 3 клика по площади комнаты (кнопки + плавный ползунок) и приоритету.
3. **Модельный ряд (актуальные складские партии):**
   - **AERA Compact (`AR-6614`)** — до 25 м² (48 см, 1.75 кг, 3 990 сом).
   - **AERA Sense (`AR-6662`)** — Хит продаж, до 30 м² (57 см, 2.85 кг, LCD + датчик PM2.5 + умный авторежим, 4 990 сом).
   - **AERA Pro X (`AR-669`)** — Флагман 360°, 30–50 м² (63 см башни, 3.5 кг, цилиндрический фильтр 360°, OLED-дисплей, 7 290 сом).
4. **Комплектации:** «Базовый» или «Плюс (2 сезона)» с дополнительным сменным фильтром HEPA H13 со скидкой 50% (+450 сом).
5. **Секция «До / После»:**
   - Интерактивный Before/After слайдер «Дымовой тест за 5 секунд» (PM2.5 500 → 005 мкг/м³).
   - Блок «Что задерживает фильтр AERA за 1 зиму в Бишкеке» с кнопкой быстрого добавления фильтра в корзину.
   - Плашка экономичности: 35 Вт ~ 25 сом/мес за электроэнергию + калькулятор очищенных литров воздуха.
6. **Липкая таблица характеристик:** первая колонка зафиксирована (`sticky`) для удобного горизонтального скролла на смартфонах.
7. **Корзина и оформление:**
   - Локальное сохранение корзины (`localStorage`) с автомиграцией SKU.
   - Выбор способов оплаты при получении (MBank, Optima Pay, Элкарт / QR, наличные).
   - Строгая маска и валидация номера `+996 (___) __-__-__` с автоопределением оператора (Mega, O!, Beeline, Salam, Бишкек).
   - Отправка заказов в Telegram через Vercel Serverless Function без раскрытия токенов клиенту.
   - Синхронное открытие диалога в WhatsApp с заполненным текстом заказа и UTM-метками.
   - Фиксация событий в Meta Pixel (`fbq('track', 'Lead')`).

## 📁 Структура проекта

```
├── index.html        # Главная страница SPA
├── app.js            # Логика приложения, корзина, маска +996, модальные окна
├── siteConfig.js     # Единый конфигуратор: товары, цены, контакты, отзывы, FAQ
├── manifest.json     # PWA Web App Manifest
├── assets/           # Локальные векторные иллюстрации и иконки
│   ├── favicon.svg
│   ├── logo-mark.svg
│   ├── og-banner.svg
│   ├── purifier-compact.svg
│   ├── purifier-sense.svg
│   ├── purifier-prox.svg
│   └── filter-hepa.svg
├── api/
│   └── order.js      # Vercel Serverless Function для защищенной отправки заказов в Telegram
├── server.js         # Локальный HTTP-сервер для разработки и тестирования
├── test.js           # Комплексный набор юнит- и E2E-тестов (Node.js test runner + Chrome CDP)
├── vercel.json       # Конфигурация статического развертывания Vercel
├── .env.example      # Пример переменных окружения
├── .gitignore
└── .vercelignore
```

## 🛠 Запуск и разработка

### Установка и запуск тестов
```bash
# Запуск полного набора автотестов и E2E в браузере
npm test
```

### Запуск локального сервера разработки
```bash
npm start
# Доступен по адресу: http://localhost:3000
```

## 🔐 Переменные окружения (Vercel)

Для работы Telegram-уведомлений о заказах добавьте переменные в настройках Vercel (`Project Settings` → `Environment Variables`):

| Переменная | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | ID чата или группы для получения заявок |
